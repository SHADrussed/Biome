# BIOME — лаборатория искусственной жизни

Клиентский симулятор на TypeScript и Canvas 2D. Без сервера, платных API и ключей.

## Запуск

```sh
npm ci
npm run dev
npm test
npm run build
npm run preview
```

## Правила

Мир 1200 × 800 начинается с 85 травоядных, 15 хищников и 420 растений. Пять наследуемых генов: скорость, радиус зрения, размер, порог энергии для размножения, продолжительность жизни. Вид наследуется; размножение бесполое. Потомок получает 42% текущей энергии родителя, ещё 12 единиц тратятся на размножение. Повторное размножение возможно через 18 секунд. Каждый ген независимо мутирует с заданной вероятностью на величину до ±20%, в физических пределах модели.

Травоядные приоритетно убегают от видимых хищников, иначе ищут ближайшее растение. Хищники преследуют ближайшую видимую добычу. При отсутствии цели существа исследуют среду с плавно меняющимся курсом. Столкновение с границей отражает движение. Пища и добыча пополняют энергию; скорость, зрение, размер и экстремальная температура увеличивают расход. Быстрые и зоркие существа эффективнее добывают пищу, но требуют больше ресурсов. Отбор возникает через различия в выживаемости и числе потомков; искусственного рейтинга приспособленности нет. Это упрощённая экологическая модель, а не научный прогноз.

Растения вырастают с частотой `abundance × 0.2 × max(0.1, 1 − abs(T − 22)/35)` в секунду. Максимум 600 существ и 1400 растений. Один «день» интерфейса — 10 секунд модели. График хранит 180 измерений с интервалом 2 секунды. Вымершие виды автоматически не восстанавливаются: используйте инструменты добавления или новый мир.

Засуха удаляет 80% растений и устанавливает рост 15%. Холод устанавливает 0 °C. Метеорит уничтожает жизнь в случайной области радиусом 240 единиц. Изменения среды сохраняются до настройки ползунков. «Новый мир» пересоздаёт популяцию и статистику, сохраняя выбранные условия. Перезагрузка страницы возвращает исходные настройки.

## Мобильные устройства

Адаптивный интерфейс, Pointer Events, Canvas с ограничением DPR до 2, requestAnimationFrame, фиксированный шаг модели 1/30 с и пространственная сетка для поиска целей. При возврате из фоновой вкладки пропущенное время не догоняется. На телефоне коснитесь инструмента, затем поля. Инспектор показывает гены, энергию и поколение выбранного существа.

## GitHub Pages

1. Добавьте содержимое проекта в GitHub-репозиторий, ветку `main`.
2. В **Settings → Pages → Build and deployment → Source** выберите **GitHub Actions**.
3. Push в `main` или ручной запуск **Deploy Biome to Pages** запускает тесты, сборку и публикацию.

`vite.config.ts` автоматически использует `/<имя-репозитория>/` на GitHub Actions через `GITHUB_REPOSITORY`; для репозитория `*.github.io` — `/`. Для своего домена задайте `BASE_PATH=/` в окружении шага сборки. Локально base равен `/`. Для проверки project Pages: `GITHUB_REPOSITORY=owner/biome npm run build`.

Google Fonts используется только для оформления, системный шрифт служит запасным. Модель полностью работает без внешних запросов. Состояние хранится в памяти вкладки.

## Диагностика баланса и статистика

В локальной корректировке порог размножения хищников-основателей равен 150–185 (травоядных 130–165); потомки наследуют фактический ген с прежними мутациями. Скорости, метаболизм и начальная энергия сохранены. В интерфейсе добавлены успешные охоты, рождения, причины смерти, средняя энергия, возраст живых и длительность завершённых жизней по видам.

[Протокол, причины вымирания и результаты до/после](experiments/REPORT.md). Воспроизведение: `npm run experiment -- baseline` и `npm run experiment -- adjusted`. Отдельная отклонённая проба: `npm run experiment -- metabolism-trial`. Все эксперименты работают локально, не запускают публикацию.
